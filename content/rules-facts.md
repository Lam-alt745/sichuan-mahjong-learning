# 四川麻将规则事实表 — Sichuan Mahjong Rules Facts

> 本文件是四川麻将规则与双语术语的**真相源**。engine 的牌型识别、胡牌判定、定缺、血战流程、番型与算分一律以此为准；缺失/存疑数值标 TODO，**不自创**。
> 来源标注：`[ZH]` = 中文维基四川麻将词条 https://zh.wikipedia.org/wiki/四川麻将 ；`[EN]` = 英文维基 Mahjong 词条 https://en.wikipedia.org/wiki/Mahjong （英文术语来源）；`[标准]` = 通行规则的标准约定（维基未明示/各平台有差异，按通行实现，存疑见 §K）。
> 抓取日期 2026-06-19。四川麻将（血战到底）各平台有番数/赔付差异，本表锁定**核心机制**；**番数 / 杠赔付 / 查叫 / 花猪等计分细则已由 项目维护者 定稿，见 §K（2026-06-21）**。

## A. 基本配置
- 玩家 **4 人**。`[标准]`
- **只用筒、条、万三门，共 108 张，无字牌（无风牌 / 箭牌）**。`[ZH]`
- 构成：每门 1–9 各 4 张 = 36 张 ×3 门 = **108 张**。`[标准]`
- 英文门花色名（`[EN]`）：万 = **Characters**（亦 myriads / cracks）；条 = **Bamboo**（亦 sticks / bams）；筒 = **Dots / Circles**。

## B. 定缺（核心特色）`[ZH]`
- 开局每人须**定缺一门**（声明放弃筒 / 条 / 万其中一门）。
- **胡牌时手牌不能超过两门**（即必须打缺所定门，胡牌成立的前提之一）。
- 英文：**Void a suit / declared void suit**（描述性 `[标准]`）。

## C. 可用动作 `[ZH]`
- **可碰（Pung）、可杠（Kong）；不可吃（no Chow）**——这是四川麻将与多数麻将的关键差异。
- 可胡牌（胡 = win / declare a winning hand）。`[EN]`
- 胡牌方式：自摸（**winning from the wall**）与点炮 / 放铳（**winning by discard**）结算不同。`[EN][ZH]`

## D. 血战到底（核心特色）`[ZH]`
- **一家胡牌后牌局不结束**，未胡牌者继续打，直到**有 3 家胡牌或流局**为止。
- 英文：**Fight to the end / Bloody battle**（描述性 `[标准]`）。

## E. 杠与「刮风下雨」`[ZH]`（赔付倍数见 §K，已定稿）
- 杠分明杠（别家打出我杠 / 碰后补杠）与暗杠（自己四张暗手）。
- 「刮风」「下雨」是杠的得分俗称（直杠 / 巴杠 / 暗杠对应不同赔付方与倍数）；维基所述倍数表述不一，**具体倍数与赔付方按所选平台规则，列入 §K**，不自创。
- 杠上开花（杠后摸牌即胡）= **win on a kong draw**（描述性 `[标准]`）。

## F. 胡牌牌型结构 `[标准]`
- 标准胡牌 = 4 个面子（刻子 / 顺子）+ 1 对将（雀头）；四川麻将不可吃，顺子只能靠摸/自身组成。
- 特殊牌型：七对（7 个对子）、龙七对（含一杠的七对，加倍）等，按平台。`[标准]`

## G. 番型（示例，番数随平台差异 — 详见 §K，L3 实现时锁定）`[ZH]`
维基所列示例（**番数为示例，最终以所选平台番表为准**）：
- 一番类：断幺九、对对和（对对胡 / All-triplets `[EN]`）、根、杠上花。
- 二番类：七对子、清一色（**Pure suit hand** `[EN]`）、全带幺。
- 英文：清一色 = Pure suit hand；对对胡 = All-triplets（All melds are pungs/kongs）。`[EN]`

## H. 查叫 / 花猪（流局结算）`[ZH]`
- 流局时检查各家牌：**未定缺成功（手中仍有三门）= 花猪**，按约定赔付。
- 未听牌（无叫）者向听牌者赔付 = **查叫 / 查大叫**（赔付额见 §K）。`[ZH]`
- 英文：听牌 = ready hand / tenpai；花猪 = "flowery pig"（描述性 `[标准]`）；查叫 = tenpai check / penalty for no-ten（描述性 `[标准]`）。

### K.2 加番项（在最大番型上叠加，受 K.5 封顶）
- 杠上花 +1 番（杠后自摸胡）｜ 杠上炮 +1 番（杠后打出被点炮；点炮者另把所杠分转给胡牌家）｜ 根 +1 番/根（四张相同未作杠，胡时每根 +1 番）
- **自摸 +1 倍底分**（加底，不加番）

### K.3 底分与倍率
- **底分 = 2 分**〔单一来源，可调；改值全表按比例缩放〕
- `n 番 = 2^(n-1) 倍`：1→×1、2→×2、3→×4、4→×8、5→×16、6→×32、7→×64、8→×128
- 得分 = 底分 × 倍率（+ 杠分 / 自摸加底等固定项）
- 番→分（底分 2）：1番=2、2番=4、3番=8、4番=16、5番=32、6番=64、7番=128、8番=256

### K.4 多家结算（血战到底）
- 点炮（荣胡 win by discard）：点炮者**一家全额赔**。
- 自摸（self-draw）：每个未胡家**各赔**（倍率分 + 自摸加底 2 分）。
- **一炮多响：点炮者对每个胡牌家分别全额赔**（项目维护者 2026-06-21）。

### K.5 封顶
- 单次胡牌**总番**（番型 + 加番）**8 番封顶**（×128 = 256 分），超出按 8 番算（项目维护者 2026-06-21）。

### K.6 杠分（刮风下雨；独立于胡牌结算，所有未胡家结算）
| 杠型 | 赔付方 | 金额（底分 2） |
|---|---|---|
| 直杠（刮风 / 点杠）| **点杠者一家赔** | 2 倍底分 = 4 分 |
| 巴杠（补杠 / 绕杠）| 每个未胡家各赔 | 1 倍底分 = 2 分 |
| 暗杠（下雨）| 每个未胡家各赔 | 2 倍底分 = 4 分 |
- 退税：流局时开杠家**未听牌** → 退回其全部杠所得。
- 抢杠胡：巴杠可被他家抢杠而胡，此时该杠刮风下雨无效。

### K.7 流局结算（摸完牌墙触发；**若已 3 家胡则不查**）
- 花猪（手中仍有三门）：向每个未花猪家赔 **16 倍底分 = 32 分**〔「16 番」口语，折算为 16 倍底分〕。
- 查大叫（tenpai check）：未听牌者向每个听牌家，按该听牌家**所听最大番型基础番（不含根 / 加番）**对应分赔付，并退杠分（退税）。口径详见 §K.8①。
- 听牌但未胡且非被查方：不赔不收。

### K.8 教学口径（项目维护者 2026-06-21 确认；四川各平台有微差异，以下为本应用教学默认，**可被真实平台规则覆盖**）
1. **查大叫**：按听牌家所听**番型基础番（`baseFan`，不含根 / 加番 / 杠分）**的最大值对应分赔付。保守清晰，避免偶然的根抬高罚分；已由 `scoring.ts` 金标锁定。
2. **天胡 / 地胡**：庄家首摸即胡 = 天胡；非庄第一圈（`turn ≤ 4` 近似）首摸即胡 = 地胡。`table.ts` 已建庄家与 `drawCounts` 字段；**不实现「第一圈无人碰杠」等平台精确边界**（教学 / 对局中近乎装饰番型，近似足够）。
